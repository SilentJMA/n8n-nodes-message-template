# Message Template wiki

`n8n-nodes-message-template` is an [n8n](https://n8n.io) community node that renders text, JSON, XML or a file from an expression template, per item or combined across all items. The [README](../README.md) is the full reference.

- Articles: [Build and test workflows with Message Template](blog-post.md) · [Map data without writing code](blog-post-data-mapper.md)

## At a glance

- **Modes:** run once for each item, or combine all items with a header, separator and footer.
- **Outputs:** text, JSON (strict or lenient), XML as browsable data with an optional formatted copy, or a file.
- **No runtime dependencies.**
